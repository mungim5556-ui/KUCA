# 안드로이드 지원 라운드 (`feature/android-support`)

지금 앱은 iOS 기준으로 만들어지고 확인됐습니다. 이 브랜치에서 **같은 프로젝트로 안드로이드도 같은 수준으로 돌게** 만든 뒤 main 에 합칩니다.
안드로이드 전용 브랜치를 계속 따로 유지하지 않습니다. 끝나면 PR 로 합치고 지웁니다. 이후에는 main 하나에서 iOS·안드로이드를 같이 빌드합니다.

- **담당:** 팀원 B (앱 화면·빌드). 이 브랜치 작업 중에는 다른 사람이 `ProjectSettings/`, `Assets/XR/`, `SampleScene.unity` 를 건드리지 않습니다.
- **표기:** <kbd>결정</kbd> = 작업자가 정할 것 (비워 둠, 정하면 `결정:` 뒤에 이름·날짜·이유와 함께 적기) · <kbd>연결</kbd> = 다른 팀원과 맞출 것

## 지금 상태 (코드에서 확인한 것)

## AR1. 필수 설정 — AR 잡기가 안드로이드에서 진짜 AR 로 열린다

- [ ] Project Settings › XR Plug-in Management › **Android 탭 › ARCore 체크** (Initialize XR on Startup 은 iOS 설정과 같게)

- [ ] 카메라 권한 거부 → 다시 열기 흐름 확인

  결정:

  결정:

## 주의
- `Library/` 폴더는 커밋하지 않습니다 (플랫폼 전환 결과가 여기 쌓임).
- `.meta` 파일은 Unity 가 만든 그대로 커밋합니다.
- 설정 변경은 가능하면 한 커밋에 하나씩 (나중에 문제가 생기면 되돌리기 쉬움).
