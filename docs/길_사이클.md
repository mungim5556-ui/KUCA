# 캠퍼스 길 사이클 (실사 기준)

> A 작성 · 2026-10-27 시작. 건물 구조물 사이클(`지도_구조물_사이클.md`, M1~M32)을 멈추고, 캠퍼스 안의 **길 · 광장 · 계단** 을 실제 모습에 맞춰 고친다.
> 사용자 요구: "도로들이 잘 드러나고 어색한 부분이 없도록", "사색의 광장 같은 공간은 모든 공간을 다 거닐 수 있음", "중앙도서관 → 학관 길의 돌계단처럼 이어지는 길 공간의 특색 · 개성이 드러나게", **실 관측 자료를 먼저 모으고**, 알아내기 어려운 구역은 사용자에게 묻는다.

## 1. 실사 요약 (VR, 10/27) — 지도에 바로 쓸 것

`[사진관찰]` = VR 에서 직접 봄, `[추정]` = 해상도가 낮거나 가려져 짐작

| 길 종류 | 실제 모습 |
| --- | --- |
| 구내 찻길 | 짙은 회색 아스팔트, 노란 겹 중앙선, 흰 차선 · 노면 글자, 흰 횡단보도, 노랑 · 흰 과속방지턱이 많다 `[사진관찰]` |
| 찻길 옆 보도 | **붉은 갈색 (벽돌빛)** 물결 맞물림 블록 또는 매끈한 붉은 포장 `[추정: 재질]`, 화강석 연석, 가로수 · 산울타리 `[사진관찰]` |
| 건물 앞 마당 · 주차장 | 밝은 회색 ~ 베이지 콘크리트 · 아스팔트에 흰(가끔 노랑) 주차선. 사람도 이 위로 다닌다 `[사진관찰]` |
| 광장 (도서관 앞 · 사색의 광장) | 흰 · 연회색 화강석 판석 격자 + 연분홍 · 연녹색 큰 십자 · 마름모 무늬, 폭 약 1 m 베이지 화강석 띠로 나뉨. 완전히 평평하고 어디든 걸을 수 있다 `[사진관찰]` |
| 건물 앞 계단 | 넓은 연회색 화강석 계단 8~15단 이상, 화강석 옆벽, 양옆 화분 · 관목 `[사진관찰]` |
| 공원 · 정원 | 잔디, 둥근 회양목, 자연석, 벤치, 낮은 정원등 `[사진관찰]` |
| 숲 계단길 | 좁은 콘크리트 계단 + 검은 쇠 난간 `[사진관찰]` |
| 운동장 | 베이지 마사토 바닥, 둘레에 회색 계단식 콘크리트 스탠드 `[사진관찰]` |

구역별 예외:
- **사색의 광장 북동쪽 끝 → 학생회관 주차장: 거친 막돌(자연석) 계단 약 5~7단, 오르막** — 사용자가 말한 "중앙도서관 → 학관 돌계단" 으로 보임 `[사진관찰, 단 수 추정]`
- **학생회관 뒤 주차장 끝: 넓은 화강석 계단 15~18단**, 쉼참 없음, 낮은 돌 옆벽, 쇠 난간 안 보임, 숲 위로 올라감 (어디로 가는지 미확인) `[사진관찰]`
- 천문대 오름길: 좁고 가파른 곧은 콘크리트 경사로, 양옆 바위 · 회양목, 끝에 화강석 몇 단 `[사진관찰]`
- 선승관 앞 마당: 작은 회색 화강석 블록 (붉은색 아님) `[사진관찰]`
- 르네상스공원: 연분홍 타일 + 드문드문 하늘색 타일 `[사진관찰]`
- 경희공원: 회갈색 물결 블록 + 회색 자갈 마당 `[사진관찰]`
- 전자정보 · 응용과학대 앞: 붉은 갈색 헤링본 벽돌 + 주황 줄 `[사진관찰]` (지도의 `BRICK_PAVE` 와 맞음)
- 종합운동장 둘레: 연회색 · 회녹색 체크 블록 `[사진관찰]`
- 연못 옆 찻길: 보도 없음, 잔디 띠만 `[사진관찰]`
- 노천극장: 화강석 판석 무대 + 반원 계단식 객석 `[사진관찰]`

지금 지도와 다른 점 (R2 에서 고칠 것):
- 지도의 보도는 모두 **밝은 베이지** → 실제 찻길 옆 보도는 **붉은 갈색**
- 계단은 R1 에서 회색 화강석 + 디딤판 줄로 바꿨지만, 도서관 → 학생회관 계단은 실제로 **거친 막돌** 이고 위치도 광장 북동쪽 끝 (OSM 보도 20 m 와 같은 자리인지 확인 필요)
- 과속방지턱 · 노면 글자 없음, 구내 찻길은 모두 같은 회색

## 3. 사용자에게 물을 것 (실사로 알 수 없음)

1. 도서관 → 학생회관 돌계단: 사색의 광장 북동쪽 끝에서 학생회관 주차장으로 올라가는 막돌 계단이 맞는지, 몇 단 · 폭 · 난간 · 쉼참
2. 학생회관 뒤 넓은 화강석 계단(15단 이상)은 위로 어디로 이어지는지 (선승관 · 생명과학대 · 다른 곳)
3. 학생회관 → 선승관 오르막: 찻길로 걷는지, 따로 보도 · 계단이 있는지
4. 생명과학대 → 체육대 찻길: 보도가 한쪽 · 양쪽 · 없음
5. 기숙사 → 학생회관: 실제로 걷는 길 (찻길 옆 보도 · 대운동장 스탠드 위 길 · 숲 계단), 중간 계단
6. 노천극장 → 천문대: 찻길(경사로)뿐인지, 숲길 · 계단이 따로 있는지
7. 대운동장 스탠드 위 산책길: 바닥과 한 바퀴 이어지는지
8. 공학관 ↔ 인조잔디구장: 스탠드 말고 공학관으로 올라가는 큰 계단 · 경사로
9. 외대 · 멀티 앞 → 대운동장으로 내려가는 계단 위치 · 모양
10. 숲길(경희공원 뒤 · 도예관 아래): 흙 · 나무 데크 · 콘크리트, 지도에 넣을 만큼 다니는지
11. 연못 둘레를 한 바퀴 걸을 수 있는지
12. 애지원: 주차장 말고 정원 산책길이 있는지, 바닥
