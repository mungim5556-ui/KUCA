## A-1. 시공간 한정 출현 (R1, 필수)

**목표:** 기획서 "특정 계절, 시간, 날씨에만 그 장소에 캐릭터가 나타남. 평소 가지 않던 공간을 가장 아름다운 순간에 방문하게 함."
**완료 기준**
- 캐릭터마다 출현 조건(계절·시간대·날씨 중 일부)이 데이터로 정의돼 있다.
- 조건이 안 맞으면 그 캐릭터는 나오지 않거나 드물게 나온다.
- 시연용으로 시간/계절/날씨를 강제로 바꿔 보는 방법이 있다 (에디터 또는 개발자 메뉴).

**지금 코드:** `CollectibleSpawner.cs` (`TrySpawn`, `PickType`), `CreatureLibrary.cs` (`TierSpecies`, `GoldZones`, `PickSpecies`), `KeyArtLook.cs` (`Season`)

**🟨 작업자가 결정할 것**
- 조건을 "안 맞으면 아예 안 나옴"으로 할지, "확률만 낮아짐"으로 할지
  결정: 순수 확률 가중 (아예 막지 않음) — Dopal-Kim, 10/09
- 시간대를 몇 개로, 어떤 경계로 나눌지 (수업 시간과 맞출지)
  결정: 4구간 아침 06–11 · 낮 11–17 · 저녁 17–20 · 밤 20–06 — Dopal-Kim, 10/09
- 24종 각각의 조건 (모든 종에 조건을 줄지, 금색만 줄지)
  결정: 24종 모두, 황금은 더 뚜렷하게 (초록·파랑 배수 0.2~3, 황금 0.15~4 + 랜드마크에서 황금 확률 = 배수/2.5) — Dopal-Kim, 10/09. 표는 `SpawnConditions.Rules`
- 조건 데이터를 어디에 둘지 (C# 표 / JSON / ScriptableObject)
  결정: C# 표 (`Assets/Scripts/SpawnConditions.cs`) — 한 곳에서 고치기 쉽게
- 조건이 안 맞아 지금 못 만나는 캐릭터를 도감에 어떻게 알려 줄지 (B와 함께)
  결정:

**🔗 맞춰야 할 것**
- 날씨를 어디서 받을지 → **결정: 기상청 단기예보 API, 서버 경유** (`GET /api/weather`, 키는 서버 설정 `Kma:ServiceKey`). 서버 코드는 C 소유라 C 에게 알림
- 도감 힌트로 쓸 데이터 형식 → B 와 합의

**AI 진행 순서**
1. "`CollectibleSpawner` 와 `CreatureLibrary` 의 출현 흐름을 설명하고, 시공간 조건을 끼워 넣을 위치를 제안해 주세요."
2. 🟨 결정 → 조건 데이터 초안을 AI에게 표로 만들게 하고, 캐릭터 설정(`Art/Concept/05_Characters/캐릭터_기획_및_제미나이_프롬프트.md`)과 어울리는지 직접 검토.
3. 구현 + "시간/계절/날씨 강제 설정" 디버그 옵션 추가.

**확인 방법:** 에디터에서 시간·계절·날씨를 바꿔 가며 Play → 해당 랜드마크에서 나오는 캐릭터가 바뀌는지.

## A-2. 희귀 색 개체 (R3) — ❌ 하지 않음

> **결정 (Dopal-Kim, 10/12):** 희귀 색 개체는 만들지 않는다. 모든 동물은 원래 모습 그대로, 황금 동물은 금색 테두리로만 구분한다. 아래 내용은 기록용.

**목표:** 기획서 "동일한 캐릭터를 잡아도 개체값이나 색깔이 달라서 희귀한 몬스터를 찾는 재미."
**완료 기준:** 같은 종에 희귀 색 버전이 있고, 지도·잡기 화면·도감에서 구분된다. 잡은 기록에 희귀 여부가 저장된다.

**지금 코드:** `Collectible.Create` (메시·머티리얼), `CreatureToy.shader` (버텍스 색), `GameProgress.Caught` (B 소유), `figures.py` (색 팔레트)

**🟨 작업자가 결정할 것**
- 희귀 확률
  결정:
- 색을 바꾸는 방식: 모델을 따로 굽기(파일 커짐) vs 셰이더에서 색조 변환(가벼움, 색 제어 어려움)
  결정:
- 종마다 희귀 색을 직접 지정할지, 규칙(예: 색조 회전·금속 광택)으로 일괄 적용할지
  결정:
- 희귀 개체를 알아보게 하는 연출 (반짝이, 이름 앞 표시 등)
  결정:

**🔗 맞춰야 할 것:** `GameProgress.Caught` 에 넣을 필드 이름·값 → B (파일 주인)

**AI 진행 순서:** 셰이더 방식이면 "CreatureToy.shader 에 색조 변환 속성을 추가하고 MaterialPropertyBlock 으로 개체마다 바꾸는 방법"부터 프로토타입 → 24종 스크린샷으로 색이 촌스럽지 않은지 직접 판단.

**확인 방법:** 희귀 확률을 100%로 올려 Play → 지도·잡기 화면·도감에서 모두 희귀 색으로 보이는지.
