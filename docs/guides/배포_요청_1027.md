## 3. 앱 — 새 APK 필요 (A)

앱 코드도 #91 에 들어 있지만, **설치된 APK 는 옛 버전**입니다.
- 옛 앱은 422 를 받으면 휴대폰 안 규칙 추천으로 넘어가서, "다시 입력해 주세요" 가 안 보이고 그냥 코스가 나옵니다.
- 메이트 코스는 서버가 정하므로 옛 앱에서도 서버 배포만으로 바뀝니다.
- 새 APK 에서 보이는 것: 입력칸 밑 빨간 "다시 입력해 주세요", 작은 기본 조건 칩, AI 해석 결과 한 줄.
